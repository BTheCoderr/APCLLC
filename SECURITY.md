# Security Policy

Security fixes target the current default branch and the production site at apcllc.co.

Report vulnerabilities privately through GitHub when they could expose quote/contact submissions, email credentials, environment variables, customer data, or server-side integrations.

Extra review is expected for form handling, email delivery, environment-variable usage, server actions/API routes, third-party data integrations, and spam/abuse protections.

Never commit production credentials, private customer inquiries, or real secret values.
