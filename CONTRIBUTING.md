# Contributing to APC LLC

This repository powers the production website for All Purpose Contractors LLC.

Before a pull request, follow the README setup and run typecheck, tests, and a production build when applicable. Check the mobile conversion path—Call, Text, Quote, service pages, and forms—whenever UI or lead-flow code changes.

Do not replace working in-app quote/contact workflows with mailto-only behavior.

A merged commit is not automatic approval for a production deployment.
